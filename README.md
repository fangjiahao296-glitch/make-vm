# Tiny stack VM

A tiny stack virtual machine for the make.fun bounty "Build a tiny stack virtual machine, 22 November 2026". It runs one program that answers all 40 instances of a set: for each instance it executes the bytecode program and writes the bytes it printed plus its exit code.
